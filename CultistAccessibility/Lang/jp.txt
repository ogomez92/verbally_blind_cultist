# Help
Help.Logo.Title = ロゴとタイトルの引用文
Help.Logo.1 = いずれかのキーを押すとメインメニューに進みます。

Help.Menu.Title = メインメニュー
Help.Menu.1 = 上下の矢印キーでボタンとテキストの間を移動します。Home と End で最初と最後の項目に移動します。
Help.Menu.2 = Enter でフォーカス中のボタンを実行します。左右の矢印キーでスライダーや選択肢を変更します。リンクと読み上げられたテキストで Enter を押すとブラウザーで開きます。
Help.Menu.3 = Escape で設定、クレジット、Mod などの開いているパネルを閉じます。
Help.Menu.4 = [[UI_CONTINUE]] でセーブしたゲームを再開します。[[UI_BEGIN_GAME]] で新しいゲームを始めます。[[UI_PURGE_SAVE]] は確認のあとセーブデータを削除します。
Help.Menu.5 = DLC と Mod のパネルには、開始できる追加レガシーとインストール済みの Mod が並びます。
Help.Menu.6 = 設定では Enter でタブを選び、下に移動してそのスライダーを操作します。キー割り当ての欄は Enter のあと新しいキーを待ちます。
Help.Menu.7 = {0} で画面全体を読み上げます。{1} でフォーカス中の項目をもう一度読みます。

Help.NewGame.Title = レガシーの選択
Help.NewGame.1 = 上下の矢印キーで、選べるレガシー、その説明、ボタンの間を移動します。
Help.NewGame.2 = レガシーで Enter を押すと選択され、その説明が下のテキスト行で読めます。
Help.NewGame.3 = [[LEGACY_START_NEW_GAME]] で選んだレガシーの新しい人生を始めます。[[LEGACY_BACK_TO_MENU]] でメインメニューに戻ります。

Help.GameOver.Title = 結末
Help.GameOver.1 = 結末の文章は画面が開いたときに読み上げられました。上下の矢印キーで 1 行ずつ読み直せます。
Help.GameOver.2 = [[LEGACY_ANOTHER_DESCENT]] で新しいレガシーを選びます。[[LEGACY_MAIN_MENU]] でメニューに戻ります。
Help.GameOver.3 = 結末の全文はレビューバッファのストーリーにもあります。Control と左右の矢印キーで切り替えてください。

Help.Crash.Title = エラー画面
Help.Crash.1 = ゲームでエラーが発生しました。ログファイルのボタンでゲームのログがあるフォルダーを開きます。終了ボタンでゲームを終了します。

Help.Options.Title = オプションメニュー
Help.Options.1 = オプションを開いている間、ゲームは一時停止します。上下の矢印キーで移動、Enter で実行、Escape でオプションを閉じます。
Help.Options.2 = 最初の項目はタブです。タブで Enter を押すと、その設定が下に表示されます。左右の矢印キーでスライダーを変更します。
Help.Options.3 = キー割り当てで Enter を押すと、新しいキーを待ちます。
Help.Options.4 = [[UI_RESUME]] でオプションを閉じます。[[UI_SAVEEXIT]] でセーブしてメインメニューに戻ります。[[UI_RESTART]] は確認のあと、この人生を最初からやり直します。
Help.Options.5 = [[UI_BROWSE]] でゲームのセーブフォルダーを Windows で開きます。

Help.Board.Title = テーブル
Help.Board.1 = テーブルには動詞、カード、コントロールの 3 つのグループがあります。左右の矢印キーでグループを切り替え、上下でその中を移動します。Home と End で最初と最後の項目に移動します。
Help.Board.2 = 動詞で Enter を押すとそのウィンドウが開きます。カードで Enter を押すと、それを受け取れる動詞の一覧が出ます。Enter で 1 つ選ぶとカードが入ります。
Help.Board.3 = コントロールには、ステータス、カードを統合するボタン、速度ボタン、オプション、キャラクター名があります。
Help.Board.4 = {2} でフォーカス中の項目のすべてを読みます: 説明、アスペクトとその意味、スロット。これらの行は詳細バッファにも入ります。
Help.Board.5 = {1} でフォーカス中の項目をもう一度読みます。{0} でグループ全体を読みます。
Help.Board.6 = {3} でキャラクターとステータスバーを読みます: 健康、情熱、理性、資金。
Help.Board.7 = {4} でゲーム速度、進行中の各動詞と残り時間、消滅しつつあるカードを読みます。
Help.Board.8 = {5} で結果が待っている次の動詞に移動します。
Help.Board.9 = 進行中の動詞がスロットを開いてカードを求めることがあります。これは読み上げられ、その動詞にフォーカスすると「スロットが開いています」と言います。時間切れになる前に、動詞を開くか、カードで Enter を押して埋めてください。
Help.Board.10 = ゲームのキー: スペースで一時停止と再開、N で通常速度、M で早送り、Tab でカードを統合、Escape でオプションメニュー。
Help.Board.11 = 一時停止していない間は時間が進みます。スペースで一時停止するのが、考えるためのいちばん安全な方法です。

Help.Window.Title = 動詞のウィンドウ
Help.Window.1 = 上下の矢印キーでウィンドウ内を移動します: ストーリーの文章、スロット、開始、結果、すべて集める。
Help.Window.2 = スロットで Enter を押すと、それに合うテーブルのカードの一覧が出ます。Enter で 1 枚選びます。スロットが埋まっている場合、最初の選択肢でカードを取り出します。
Help.Window.3 = スロットで {6} または Backspace を押すと、そのカードをテーブルに戻します。
Help.Window.4 = カードを置くとウィンドウの予測が変わります。新しいレシピ名が読み上げられ、開始できるときは「開始可能」と言います。
Help.Window.5 = 開始で Enter、またはゲームのキー S でレシピを始めます。結果で Enter を押すとそのカードをテーブルに取ります。すべて集める、またはゲームのキー C ですべて取ります。
Help.Window.6 = ストーリーの文章で Enter を押すと全文を読みます。Page Up と Page Down、またはストーリーの文章上で左右を押すと、長いストーリーのページをめくります。
Help.Window.7 = Escape でウィンドウを閉じます。開始していない動詞のスロットに残したカードはテーブルに戻ります。
